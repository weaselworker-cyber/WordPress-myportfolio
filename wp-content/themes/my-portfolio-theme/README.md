My Portfolio Theme

１．概要
WordPressのオリジナルテーマとして制作したポートフォリオサイトです。
HTML/CSS・JavaScript・PHPを使用してレスポンシブ対応（スマホ幅600px以下）や制作実績の管理、問い合わせフォームを実装しました。

２．実装した機能
・基本機能
-Hero、About、Skills、Works、Contactの各セクションを作成
-PC・スマートフォンに対応したレスポンシブデザイン
-HeroセクションにCSSアニメーションを実装
-Skillsセクションにスキルレベルを表すプログレスバーを実装
-WordPressのテンプレートをheader.php、index.php、footer.phpに分割
-WordPressのメニュー管理機能（wp_nav_menu）に対応

・制作実績機能
-カスタム投稿タイプ「works」を登録
-アイキャッチ画像に対応
-WP_Queryを使用して制作実績を動的に一覧表示
-詳細ボタンからモーダルウィンドウを表示
-×ボタンと背景クリックによるモーダルの閉じる処理を実装

・JavaScript機能
-スクロール量が200pxを超えるとトップへ戻るボタンを表示
-ボタンクリックでページの先頭までスムーズにスクロール

・お問い合わせ機能
-Contact Form 7を導入
-サイトのデザインに合わせてフォームをカスタマイズ
-WP Mail SMTPを使用してメール送信を設定
-Gmailへのテスト送信を確認

・セキュリティ対策
-esc_html()によるタイトルのエスケープ
-wp_kses_post()による投稿本文の安全な出力
-esc_attr()によるHTML属性値のエスケープ
-WordPress標準関数を利用した画像・メニューの出力

３．制作時の工夫ポイント
-習得スキルをプログレスバーで表現
-モーダル実装でよりコンパクトなWebサイトをデザイン
-白・黒・青のシンプルなデザイン
-Worksセクションでカスタム投稿タイプを利用して管理画面からいつでも制作実績およびURLを追加することが可能に

４．苦労したエラーと解決方法

エラー：「詳細を見る」ボタンを押したときにページ内にモーダルが表示されてしまう問題
解決方法：モーダルクラスのCSSにposition: fixed;を設定

エラー：コンタクトフォームからメールが送信できない問題（ローカル環境にメールサーバーがない）
解決方法：方法を模索して最終的に「WP Mail SMTP」を導入することでメールを正常に送受信可能に
